# Бэклог по чужим решениям (не копировать код)

Разбор публичных репозиториев команд того же спец. трека ФСП. Цель: идеи и приоритеты для нашего Spring-бэкенда. Чужой исходный код не переносим, реализуем своими слоями и контрактом.

Источники:

- [lct_hackathon_fcp](https://github.com/Zhaba1337228/lct_hackathon_fcp) (Go + Fiber, «Контур талантов»)
- [fsp-talent](https://github.com/SergeyFilyanov/fsp-talent) (Python FastAPI, «ФСП Таланты»; API GitHub без токена отдаёт 404, разбор по README)

Скан: 2026-10-05. Наш стек остаётся Java 21 / Spring Boot.

## Что уже есть у нас

Категория по опросу+тесту, Keycloak, приглашения с зарплатой, скрытие контактов до ACCEPT, анкеты с весами, LLM parse резюме, Docker Compose, документация 3.4.

## Средний приоритет

| Идея | Откуда | Комментарий |
|------|--------|-------------|
| Паспорт навыков: 4 компетенции с источником и датой | lct | Карточка для работодателя, не только categoryCode |

| 10 IT-направлений и 6 грейдов (Intern…Principal) | lct | Мы: 6 IT + 4 грейда; расширить справочник |
| Избранное / уточнение запроса без потери подборки | fsp needs | ТЗ прямо просит |
| Помощник в ЛК с fallback без LLM | fsp GigaChat + knowledge.py | Свои сценарии + Infereco |

## Низкий приоритет / не тащить как есть

- Привилегированный code-arena на ядре хоста (lct DEMO): для нас опасно и тяжело по RAM.
- Офлайн TF-IDF корпус и отдельный Python ML-сервис: у нас уже LLM gateway.
- Windows-only start-local.ps1: нам достаточно bash/compose.
- Копирование их банков заданий и UI: лицензия чужого хакатон-кода и риск «клон».

## Не копировать

Чужие миграции, seed-ответы, семейства задач, sandbox-образы, Caddyfile/секреты, деплой-скрипты с IP/SSH. Берём только постановку фичи и критерии приёмки.
