# Механика подбора и категоризация

## Категория

`categoryCode = INDUSTRY:SPECIALIZATION:GRADE`  
Источник: опрос + тест. Поля резюме на категорию не влияют.

## Ранжирование внутри категории

```
score = 0.45 * cosine(needVector, surveyVector)
      + 0.25 * stackOverlap
      + 0.20 * testScore
      + fspBonus(points)   # до +0.20
```

## Explain

2–4 причины на русском: категория, совпадение весов, стек, тест, ФСП (или отсутствие истории ФСП).

## Сценарий контакта

Работодатель → подборка → invitation (зарплата обязательна) → кандидат accept/decline.  
Контакты кандидата раскрываются только после ACCEPTED.
